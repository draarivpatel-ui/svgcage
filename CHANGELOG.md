# Changelog

## 1.0.0

Initial release.

- Strict bounded XML tokenizer and tree builder for SVG input
- Allowlist SVG sanitizer with canonical re-serialization
- XSS, event handler, script URL, embedded content, CSS injection, XXE, DTD, processing instruction, SSRF, namespace confusion, coordinate abuse, path bomb, and use expansion defenses
- Non-mutating audit API, boolean validation helpers, immutable policy objects, ESM, CommonJS, TypeScript declarations, and a cross-platform CLI
